# Estudos de Caso

Esta pasta reúne exemplos aplicados do modelo mental.

O objetivo não é criar receitas universais, mas demonstrar como os princípios aparecem em decisões concretas de modelagem, integração, arquitetura e implementação.

## Casos sugeridos

* Modelagem de boleto com estados finais explícitos.
* Integração por eventos entre pagamento, faturamento e notificação.
* Uso de CDC para consumidores analíticos sem contaminar o domínio.
* Registro de uma decisão arquitetural em ADR.
